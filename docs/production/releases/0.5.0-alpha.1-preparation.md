## Narrow packaging correction

The workflow copied CEF runtime resources but did not expose their embedded
licences as readable files. `collect-cef-notices.mjs` now extracts the pinned
CEF licence and Chromium credits/CSS/JS from resources.pak in the Windows build
output. It rejects missing IDs, invalid bounds/compression and stale notices;
fixture tests run before extraction. Angular's 3rdpartylicenses.txt is retained.
This changes packaging only, with no dependency update or game execution.
The remaining dependency redistribution/notice review (including Discord SDK
and statically linked libraries) must be completed before a public package;
these extracted notices alone are not a claim of exhaustive licence clearance.

## Minimal human validation, only after separate authorization

1. Identify the ZIP SHA-256 and source SHA, dependencies, ESP hashes/load order
   and test roles. Use a clean test profile and separate backup-protected saves/
   campaign; no new Windows account or second game installation is required.
   Verify installation layout, external fireplace textures and absence of old
   binaries/private intro; do not silently reuse a DEV package.
2. Manually launch the supplied SkyrimTogether.exe: menu/background/input and
   normal exit, actual SKSE dependency loading and no runtime/address errors.
   In the selected Solo path check creation, seating, Valen access and save/load.
3. Use the same package on two human-controlled clients and server, recording
   host/client/observer roles. Check admission/lobby, creation, reciprocal
   appearance, seating, movement and the selected Helgen/Valen progression.
4. Run the applicable campaign matrix agreed for this slice: sealed roster
   refuses late join/replacement; a disconnect locks progression; a committed
   checkpoint collectively restores the same shared state with each player's
   own exact native save bundle; relevant crash/restart/failed-restore cases
   fail safely. Record World Sync manipulation/interruption/late materialization
   separately where included. Stop on corruption, divergence or progression
   blockage and triage it before release.
5. Retain identities, concise observations and useful diagnostics for the exact
   archive. Do not infer unreported permutations or claim a complete matrix
   from this minimum protocol. Codex does not execute these steps here.
