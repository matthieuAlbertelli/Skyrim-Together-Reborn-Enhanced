`NativeAdapter.h` owns the exact optional admission, music-call byte/range
preflight and the shared write-permission transaction used by production and
tests. All permission acquisitions precede a non-failing commit; failure unwinds
acquired permissions in reverse without touching any patch or original pointer.
An altered method/call is rejected before this transaction. Unknown runtimes,
including 1.6, cannot activate presentation. Optional O02 qualification does not
weaken the independent campaign gate. DialogueProgress, appearance diagnostics,
World Sync, save/load, return-to-menu and ADR-0018 are unchanged.
