## Local dependency evidence

The explicitly inspected Steam install contains Skyrim `1.6.1170.0`, SKSE DLL
`skse64_1_6_1170.dll` with file resource `0.2.2.6`, BetterGrabbing DLL with file
resource `0.1.12.0`, and CCExtender resource `1.12.0.1.0`. Resource versions do not
by themselves establish mod package versions. Other root DLLs include Steam API,
Bink, WinHTTP and CKPE components. No installed file was loaded as a game/plugin
by this audit. The exact 1.7 EXE/SKSE and Better Grabbing 2.0 integration were
not available/proved in this inspected environment.

The installed v5 database has 565,759 slots, 435,162 nonzero entries, max offset
`0x3804830`, SHA-256
`8aab3dd251d135b849bd983f86a4a205c920fa3e81f8e30c0e63ccfef9423842`.
The new C++ reader also reads the installed v2 table (428,461 entries).
The v5 read-only probe uses the loader's maximum capacity, not a measured 1.7
image extent; actual startup requires the checked target EXE's SizeOfImage.
No Bethesda executable or third-party database is committed as a fixture.

identify v13 and the exact Steam 1.7.104 table.
