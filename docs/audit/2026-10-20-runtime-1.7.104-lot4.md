| Surface | Source evidence | Current consequence |

| Steam bootstrap | `steam/SteamLoader.cpp::Load` writes `steam_appid.txt` into selected game root, then locates Steam through HKCU | Choosing the existing installation permits an installed-file write |

| STRE local identity | `campaign_client/CampaignIdentityStore.cpp::ResolveDefaultRoot` uses LOCALAPPDATA/SkyrimTogetherRebornEnhanced | Existing local identity/binding store remains reachable |
| STRE/CEF | `TiltedOnlineApp` rotates app-relative client log at5MiB/3; `OverlayApp` uses GetPath logs/cache, or TEMP cache for extra instances | App-local payload helps, but does not isolate all outputs; actual GetPath/CEF initialization unobserved |

## Concrete unblock and next boundary

Preferred next environment: a maintainer-provisioned dedicated Windows test
account on this same PC, with its own initialized Documents/AppData/HKCU and
legitimate Steam session/library arrangement that preserves the original
installation and shared configuration. Account/credentials/session setup needs
maintainer intervention under the mission; no account was created here.
Then assemble a coherent independent Steam game and minimal plugin profile,
copy this payload, verify all paths/links/identities again, and rerun preflight.

An alternative is a reviewed complete process-level filesystem **and registry**
isolation solution covering Skyrim, SKSE and CEF children. An EXE copy, Vortex
profile, environment-variable override or backup-and-restore alone is not that
proof. Modifying current-user Known Folders/HKCU would affect shared state and
requires a precise separate maintainer decision; this lot does not perform it.

The already-authorized next test remains only main-menu startup/interactions/
normal exit on the main PC. O02/O03/D01 fallback remains expected. Save/Continue,
solo creation/appearance, seating, multiplayer and checkpoints cannot become
the next validation lot until startup has actually passed and the maintainer
extends the scope. Issue99 remains open; no global1.7 compatibility is claimed.
