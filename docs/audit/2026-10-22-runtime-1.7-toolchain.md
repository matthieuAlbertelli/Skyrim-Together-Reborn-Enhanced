## Bounded adaptation and effects review

The local wrapper really still required exact `1.6.1170.0`; it now requires exact
`1.7.104.0`. Missing/versionless/unreadable files and wrong versions remain
blocking, with path/version diagnostics. `Inspect` and `PapyrusStatus` no longer
require xEdit; preparation/full preflight/import still do. New sessions bind the
runtime path/version/hash. Public import/finalization rejects missing historical
runtime evidence or a changed runtime rather than relabeling an old attestation.

The prebuilt AutoMod DLL is invoked directly with `dotnet <DLL> --json`, replacing
`dotnet run --no-build --no-restore --project`. Inspected CLI handlers for ESP
info/list/read and add-global use in-process Mutagen; dry-run skips SavePlugin.
Papyrus status checks local files. ToolDownloader constructs an HttpClient but
only its separate download action sends requests; that action is not used.
No reviewed invocation calls setup/download, an authoring adapter or an editor.
The selected source files and CLI dependencies are fingerprinted separately.

`compiler-static-il.txt` comes from metadata/IL decoding, without loading target
assemblies. Ordinary compilation calls the colocated PapyrusAssembler. The
separate AST graph path can call `dot.exe`; no graph option is selected. Native
assembler imports/strings were inspected; it is the existing compiler companion,
not CK/xEdit. CLI runtime evidence must still come from actual executions below.

No HEDR, FormVersion, master/record production data or PEX bytecode version is
migrated. The synthetic HEDR 1.7 is a **plugin format field**, not Skyrim 1.7.104.
Typed GLOB rereading now also checks GlobalFloat type, not merely EditorID/value.
UNC/device/network-drive paths are rejected before traversal, and reparse
ancestors before descendants; denied access is never silently treated as absence.

All existing allowlists, STRE_ IDs, option/path rejection, strict one-object JSON
Boolean success, exit/stderr checks, dry-run hash proof, independent backups,
format/master checks, Git ancestry/clean-source checks, exact human receipts and
production import ownership remain. No fetch/merge, relaxed ancestry or new
permission framework was introduced. Tests create their own local origin/main ref.
