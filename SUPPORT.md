# STRE Support

STRE is a volunteer-maintained alpha project. The community can help diagnose problems, but compatibility with every mod list, load order, Skyrim runtime, network environment, or save cannot be guaranteed.

## Before asking for help

1. Read the [player installation guide](docs/user/INSTALLATION.md) and [compatibility matrix](docs/testing/COMPATIBILITY_MATRIX.md).
2. Confirm the STRE build and Skyrim runtime you are using.
3. Keep the client and server logs from the affected session.
4. For multiplayer problems, record the number of players and whether each observation came from the host, a client, or another observer.

## Choose the right channel

- **Installation, configuration, compatibility, or gameplay help:** use [GitHub Discussions / Q&A](https://github.com/matthieuAlbertelli/Skyrim-Together-Reborn-Enhanced/discussions/categories/q-a).
- **Reproducible STRE defect:** use the [bug report form](https://github.com/matthieuAlbertelli/Skyrim-Together-Reborn-Enhanced/issues/new/choose).
- **Feature idea:** start an [Ideas discussion](https://github.com/matthieuAlbertelli/Skyrim-Together-Reborn-Enhanced/discussions/categories/ideas). Maintainers will create or request an actionable issue when an idea is accepted for implementation.
- **Security vulnerability:** follow [SECURITY.md](SECURITY.md) and report it privately.
- **Upstream Skyrim Together Reborn problem:** STRE may still track campaign impact, but fixes owned entirely by upstream should also follow the upstream support process.

Modded reports are welcome. Include a mod-list export, collection link, profile, or load order when available. Maintainers may request a vanilla or minimal reproduction to isolate ownership, but a report is not rejected merely because mods are installed.

Do not post passwords, access tokens, private server addresses, personal data, copyrighted game files, or unredacted sensitive logs.
